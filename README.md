# Smart Vehicle Assistance System

## Project Description
This project is developed using C++ and Object-Oriented Programming concepts to demonstrate a basic Smart Vehicle Assistance System.

## Features
- Simulated Camera, Radar, and Ultrasonic sensor readings
- Rule-based vehicle risk analysis
- Illustrative safe-speed recommendation
- Technician search based on the selected location
- Linear search to find matching technicians

## Concepts Used
- Classes and Objects
- Encapsulation
- Inheritance
- Abstraction
- Runtime Polymorphism
- Function Overloading
- Arrays of Objects
- Linear Search

## Programming Language
C++

## Note
Sensor readings are simulated for demonstration purposes. This project is an educational prototype and does not control a real vehicle.
